Web-Based Management Information System for Barangay Maybancal Health Centers and Rural Health Unit of Morong, Rizal

Project 04

RSST Attendance Monitoring System for Senior High School

An application-based attendance monitoring system developed to streamline the process of recording, managing, and tracking student attendance. The system provides a centralized platform for managing student information, subjects, users, and attendance records, helping make attendance monitoring more organized and efficient. I developed the application interface and core functionality, implemented the Subject, Attendance, Students Records, and User Management modules, worked with Node.js for backend functionality and system operations, and handled testing, debugging, and improvements.

Key Modules & Features

  • Subject Module Manages subjects and their corresponding information for student attendance monitoring.
  • Attendance Module Records and tracks student attendance for different subjects and schedules.
  • Students Records Module Manages and organizes student information and records.
  • User Management Module Manages system users, user information, and access to the application.

Application Development

The system was developed as an application using Android Studio, with Node.js used for backend functionality and communication between the application and its services. This project provided hands-on experience in developing application interfaces, implementing system operations, handling data, and connecting the application to backend services.

# Ariel B. Eubanas Jr. — Developer Portfolio

Personal developer portfolio for **Ariel B. Eubanas Jr.**, a Computer Science graduate and software developer focused on **Web & AI Development**.

## Built With

- HTML5
- CSS3
- JavaScript

## Portfolio Features

- Responsive single-page layout
- Dark violet / blue developer theme
- Static professional profile image
- Technical skills and development capabilities
- Four featured software projects
- Expandable project details
- Development experience
- Education
- Contact information
- Mobile, tablet, laptop, and desktop support

## Run Locally

1. Open the project folder in Visual Studio Code.
2. Install the **Live Server** extension if needed.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

## Privacy & Confidentiality

This public repository contains only portfolio files intended for public viewing.

Confidential project source code, private screenshots, databases, credentials,
environment files, client information, and other protected material are intentionally
excluded. The `.gitignore` file includes additional protection against accidentally
committing private development files.
